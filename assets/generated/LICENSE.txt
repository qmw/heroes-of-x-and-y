H3online generated art
======================

Every image in this folder (assets/generated/) was generated for this project with OpenAI image
generation via Codex CLI (https://developers.openai.com/codex/cli), from original prompts written
for this project (tools/genart/build-prompts.mjs, tools/genart/prompts.json), and then downscaled /
trimmed / recoloured by the project's own tools (tools/genart/resize.mjs).
